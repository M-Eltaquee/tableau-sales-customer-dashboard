About This Project

Sales managers and executives needed a clear year-over-year view of sales performance, while marketing and management needed visibility into customer behavior and segmentation. This project builds two connected Tableau dashboards to serve both audiences from a single Superstore-style dataset.

Built as two linked dashboards — Sales Dashboard and Customer Dashboard — navigable via icon-based dashboard actions. Followed a full requirements-first workflow: user story definition, Excalidraw mockup, then build. Uses a single Select Year parameter to drive every current-year vs. previous-year comparison across both dashboards.

Dataset

Superstore-style retail dataset covering orders, products, and customers across multiple years — order grain, with Order Date driving all time-based analysis (not Ship Date).

Field groups

CategoryFields
OrdersOrder ID, Order Date, Ship Date, Customer ID, Product ID, Sales, Profit, Quantity, Discount
CustomersCustomer ID, Customer Name, Segment
ProductsProduct ID, Category, Sub-Category
LocationRegion, State, City

Ship Date exists in the source data but is deliberately excluded from every KPI and trend calculation — all current/previous-year logic is anchored to Order Date only.

Calculated Fields & Parameters

One parameter drives every current-year / previous-year comparison on both dashboards — no hardcoded year values anywhere in the workbook.

Core building blocks

FieldLogic
Select Year (Parameter)Integer list, populated from YEAR(Order Date) — the single control point for both dashboards
CY Sales / CY Profit / CY QuantityIF YEAR([Order Date]) = [Select Year] THEN [Sales/Profit/Quantity] END
LY Sales / LY Profit / LY QuantityIF YEAR([Order Date]) = [Select Year] - 1 THEN [Sales/Profit/Quantity] END
YoY % variance(SUM([CY measure]) - SUM([LY measure])) / SUM([LY measure])
Peak / Trough highlightWINDOW_MAX / WINDOW_MIN table calculations on the monthly trend, marking the highest and lowest month for the selected year

Sparkline highlight dots use a dual-axis merge on the same pill to decouple marker formatting from the line itself, a standard Tableau technique for annotating specific points without a second chart.

Design & Interactivity Requirements

Dashboard Dynamic

The dashboard allows users to check historical data by selecting any desired year via the Select Year parameter. Navigation icons let users move between the Sales and Customer dashboards without leaving the report. Charts and graphs are interactive — clicking a mark filters the rest of the dashboard through dashboard actions.

Data Filters

Users can filter by product information (Category, Sub-Category) and by location information (Region, State, City), applied consistently across both dashboards.

Key Takeaways

Sales, profit, and quantity all grew YoY

Total Sales +20.4%, Total Profit +12.5%, Total Quantity +26.8% vs the previous year.

Machines is a revenue/profit mismatch

Sizeable sales volume but a net loss — the bar-in-bar view surfaces this instantly, a plain sales ranking would have hidden it.

Weekly volatility is visible, not just monthly

Above/below-average week highlighting shows short-term swings that a monthly-only view would smooth over.

One parameter drives the whole workbook

A single Select Year parameter powers every CY/PY comparison on both dashboards — no duplicated year logic anywhere.

Known Issues

LY Sales returns null when Select Year is on the first year in the dataset. If the parameter is set to the earliest year available, there is no prior year to compare against — every month's LY calculation returns null, and the previous-year line disappears rather than showing zero. This is expected behavior given the calculation logic, not a broken chart, but it isn't self-explanatory to a viewer. Fix under consideration: an on-chart message ("No prior-year data available") instead of a silently empty line when this condition is detected.

Ship Date correctly excluded from the date model. All KPIs and calculated fields are explicitly anchored to Order Date. Ship Date is present in the source data but was deliberately kept out of every time-based calculation to avoid inflating or shifting the reporting range.
